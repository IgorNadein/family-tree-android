# Family Tree / Семейное древо

Самостоятельное Android-приложение для ведения семейного древа, основанное на [Family Gem](https://github.com/michelesalvador/FamilyGem).

## Разработка

- GitHub: https://github.com/IgorNadein/family-tree-android
- Основная машина: `nadein-core`
- Каталог: `~/Dev/family-tree-android`
- Android applicationId: `ru.nadein.familytree`
- Версия форка: `0.1.0`; ветка разработки: `master`

Ветка исходного проекта сохраняется отдельно как `upstream`, чтобы можно было переносить полезные исправления.

## Состояние

Базовые возможности работы с генеалогическим древом унаследованы от Family Gem. Собственный пакет Android позволяет устанавливать приложение параллельно с оригиналом, не разделяя его sandbox и данные приложения.

**Ограничения:** некоторые функции исходника обращаются к сервису `familygem.app` (совместное использование деревьев, платные возможности). У нового проекта пока нет собственного сервера, учётных записей и реализации этих онлайн-функций. Перед релизом нужно отключить либо заменить такие интеграции. APK новой версии пока не собран и не проверен на устройстве.

Инструкции для разработки: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
