# Объединение двух карточек одного человека (0.2.9)

Назначение: убрать **подтверждённый дубль** внутри одного дерева.
Это **не** автоматическое отождествление людей по фамилии или дате рождения.

## Порядок действий

1. Сделать резервный экспорт .ftree основного дерева.
2. Открыть карточку того человека, **чей ID должен остаться**.
3. Меню (⋮) → «Объединить с другим человеком».
4. Найти вторую карточку по имени, году или ID.
5. Проверить имена, даты рождения/смерти, число заметок и ссылок,
   число семей. Нажать «Объединить людей» только после подтверждения
   личности человека.
6. Приложение переносит имена, факты, заметки, источники, медиа и
   допустимые семейные связи, удаляет вторую карточку и обновляет
   все GEDCOM refs, указывавшие на её ID.
7. Изменения автоматически сохраняются в дереве и **новом коммите**.

Не выполняется слияние, когда доказуемо возникают недопустимые связи:
«человек становится своим родителем», «человек становится супругом
самого себя» или соединяются разные известные родительские семьи.
Равно как запрещено слияние противоречивых значений полей, которые
невозможно объединить без потери сведений. Разные данные о рождении
или смерти при подтверждении объединения сохраняются оба с предупреждением.
Вторую карточку, если она корень дерева, объединять нельзя — её следует
открыть как основную.

## Откат

На экране списка деревьев открыть меню дерева → «История» → нужный
коммит, предшествовавший объединению → «Восстановить версию».
Восстановление добавляет **новый коммит**, сохраняя прежние коммиты и
медиа. Старые записи не удаляются из истории.

Обе операции работают с **одним** деревом. Перенос людей между разными
деревьями и .ftree-history merge — отдельные механизмы.

## Тесты

Проверены многобрачие, дети разных браков, дублирующиеся ссылки
на детей, сохранение медиа/источников/заметок, конфликты предков,
противоречивые половые признаки и родительские семьи, изменения
референсов в ассоциациях, откат с новым коммитом истории.
Дополнительно локально проверена операция над синтетическим дублем
в большой копии реального дерева; исходный архив не изменялся.
