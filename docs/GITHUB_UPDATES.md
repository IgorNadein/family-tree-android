# Обновления Family Tree через GitHub Releases

В приложении: **О программе → Проверить обновления в GitHub**.

- Используется API последнего стабильного GitHub Release.
- Перед установкой сверяются номер версии, имя пакета,
  SHA-256 файла и сертификат APK с уже установленным приложением.
- Установка выполняется только штатным установщиком Android после
  подтверждения пользователя. Деревья не удаляются и не изменяются.
- Нужен один первоначальный переход на версию 0.2.8 через APK со
  страницы Releases. Следующие версии скачиваются из приложения.
- Android может единожды попросить разрешение на установку из приложения.

## Новый выпуск без Termux

1. Увеличить versionCode и versionName в app/build.gradle.
2. Создать PR и объединить изменения с master.
3. Workflow .github/workflows/release.yml проведёт тесты,
   соберёт APK и проверит подпись и номер версии.
4. Выпуск vX.Y.Z с APK и контрольной суммой будет создан автоматически.
5. Пользователь видит выпуск при проверке из раздела «О программе».

В GitHub Actions Secret FAMILY_TREE_SIGNING_KEYSTORE_B64 хранится прежний
ключ подписи. Он нужен для установки поверх имеющегося APK. Workflow
никогда не публикует ключ. Не удалять Secret и не менять сертификат
без заранее спланированной миграции.

Важно: для совместимости с установленными версиями используется старый
сертификат локальных debug APK. Для широкой публичной дистрибуции
нужен отдельный план перехода на производственную подпись, исключающий
потерю данных при обновлении.
