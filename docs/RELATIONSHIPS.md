# Семейные отношения и несколько браков

## Версия 0.2.2: выбор родителей при добавлении ребёнка

GEDCOM хранит браки / семейные группы в отдельных записях FAM. Ребёнок
ссылается на конкретную семью через FAMC (ParentFamilyRef). У одного
человека может быть несколько FAMS (SpouseFamilyRef).

### Сценарий: второй муж после смерти первого

- Мать + первый муж — семья F1, первый ребёнок принадлежит F1.
- Мать + второй муж — семья F2, второй ребёнок принадлежит F2.
- Первый муж **не является отцом** второго ребёнка, если ребёнок
  включён в F2; семья F1 не должна получать ссылку на второго ребёнка.
- Дата смерти первого мужа не переключает родительскую семью автоматически:
  пользователь **явно выбирает родителей**.

### Правила пользовательского сценария

1. В **обычном режиме** при добавлении ребёнка к родителю, у которого
   уже есть хотя бы одна семья, всегда открывается список выбора.
   В вариантах показаны именно родители, а не перечень детей.
2. В **экспертном режиме**, если у родителя несколько семей и
   контекстная семья не указана, первым пунктом отображается
   «Выберите родителей ребёнка…». Он не создаёт связь; кнопка
   подтверждения неактивна до явного выбора.
3. Если пользователь начал действие из конкретной семьи на диаграмме,
   выбранную семью можно предварительно отметить.
4. В любом режиме можно выбрать «Новая семья для [родитель]»,
   чтобы не назначать прежнего партнёра отцом ребёнка при неизвестном
   другом родителе. Второго родителя разрешено добавить позднее.
5. При наличии ровно одной семьи экспертный диалог по-прежнему
   показывает её выбранной; пользователь видит и при желании
   меняет семью перед подтверждением.
6. Существующие записи семей **не исправляются автоматически**:
   изменение отцовства задним числом требует осознанной правки связей.

### Регрессионные тесты

- `MultipleMarriagesTest`: два мужа, разные дети, независимые FAMC,
  проверка после сериализации и повторного чтения GEDCOM/JSON.
- `ChildFamilySelectionPolicyTest`: выбор родителей при нескольких
  семьях без контекстной предпочтительной семьи.
- `MultipleMarriagesUiTest` (Android эмулятор): выбор второй семьи в
  экспертном/обычном режимах; создание ребёнка в F2 без попадания в F1;
  недопущение автоматического выбора умершего первого мужа, когда в
  данных ещё существует только его семья.

Необходимо продолжить тесты усыновления, отчимов, разводов,
повторного вступления в брак с тем же человеком и нескольких FAMC.
