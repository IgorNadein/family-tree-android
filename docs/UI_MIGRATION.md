# Интерфейс Family Tree — поэтапная миграция

## 0.3.0 — первая итерация Compose

В одной Android-аппликации временно сосуществуют классические Android Views
и Jetpack Compose. Это позволяет сохранять функциональность Family Gem,
пока мы переносим экраны.

### Новые компоненты

- `ui/FamilyTreeTheme.kt` — единая тема Material 3, светлая и тёмная
  палитры, динамические цвета на Android 12+.
- `ui/TreeRowCard.kt` — новый внешний вид семей в общем списке:
  закруглённая карточка, инициал, название, статистика; отдельное
  оформление производных/недоступных деревьев.
- `ui/CreateTreeDialog.kt` — Compose AlertDialog с полем названия дерева.
- `TreesActivity.kt` по-прежнему управляет списком, меню действий,
  перетаскиванием, автоматическим открытием последнего дерева, баннерами,
  экспортом, резервным копированием и навигацией.
- `NewTreeActivity.kt` по-прежнему выполняет импорт, загрузку образца,
  восстановление резервных копий и само создание дерева.

### Инварианты

1. Изменение визуального представления не изменяет формат GEDCOM/JSON,
   резервные копии, семейные связи и пакет `ru.nadein.familytree`.
2. Идентификаторы меню, кнопок и переходов оставлены прежними;
   пользовательские сценарии не требуют миграции данных.
3. Сохраняется `minSdk=23`; Java/Kotlin переходят на JVM target 11
   для современного Compose с Android desugaring.
4. Compose Compiler закреплён за Kotlin 2.4.21; BOM Compose в Google Maven
   закреплён за проверенной доступной версией 2026.09.00.
5. Пока переиспользуется старый `ListView`, карточки Compose не владеют
   обработчиками клика и drag-and-drop. Контейнер дерева сохраняет
   существующие слушатели.
6. Оставшиеся экраны и модальные окна пока не перенесены на Compose.

### Проверки на реальном Android-устройстве

- Открыть дерево нажатием на новую карточку; вернуться к списку.
- Открыть меню ⋮, проверить информацию, переименование, экспорт и удаление.
- Переставить два дерева долгим нажатием и проверить порядок после перезапуска.
- Создать новое дерево через современный диалог, проверить русские названия.
- Проверить тёмную тему, узкий экран и поворот устройства.
- Проверить импорт GEDCOM и восстановление ZIP; сравнить с 0.2.0.
- Проверить редкие состояния: производное/недоступное дерево, резервная копия,
  автоматический переход по уведомлению.
