# .ftree: обмен семейными деревьями с историей

Первая версия протокола (Family Tree 0.2.3). Формат рассчитан на
обмен файлами без сервера, а не на синхронизацию с GitHub.

## Как пользоваться

1. В списке деревьев откройте меню ⋮ → «Экспорт с историей (.ftree)».
   Прочтите предупреждение о персональных данных и выберите папку.
2. Передайте файл родственнику любым способом. Отправка не происходит
   автоматически и не требует серверов.
3. Родственник выбирает «Добавить дерево» → «Импорт с историей (.ftree)».
   Копия сохраняет идентификатор исходного дерева и все ревизии.
4. Родственник редактирует дерево, сохраняет изменения и экспортирует
   новый файл .ftree.
5. У отправителя: ⋮ у исходного дерева → «Объединить из .ftree».
   Приложение находит общего предка двух копий и показывает конфликты.
   Для каждого конфликта выберите «Оставить мою» либо «Выбрать из файла».
   Отмена не меняет дерево.
6. ⋮ → «История изменений» показывает время и идентификаторы ревизий.

Если при импорте обнаружится дерево с таким же UUID, приложение предложит
объединение или создание отдельной копии.

## Формат и алгоритм

- Файл .ftree — ZIP, содержащий manifest.json, title.json и каталог
  commits с SHA-256 идентификаторами коммитов.
- Manifest содержит версию протокола, UUID семейного дерева и хеш
  последней ревизии.
- Коммит содержит снимок GEDCOM JSON, временную метку, метку автора
  «Local device», одного или двух родителей и SHA-256.
- Трёхстороннее слияние сравнивает локальную и полученную версии с
  их общим предком. Отдельные люди и семейные группы объединяются
  по стабильному GEDCOM ID. Редактирование двух разных записей сливается
  автоматически. Разные правки одной записи требуют выбора пользователя.
- После слияния создаётся ревизия с двумя родительскими коммитами,
  обе линии истории сохраняются.
- Архив проверяется: повреждённые хеши, непредусмотренные ZIP-файлы,
  повторные пути, несовместимая версия, разорванная история и некорректные
  родственные ссылки блокируются.
- Ограничения версии 1: 16 МиБ на ZIP-запись, 64 МиБ на содержимое ZIP,
  не более 1024 коммитов.

## Безопасность и ограничения

**Файл НЕ зашифрован** и может содержать личные данные живых людей.
Передавайте его только доверенным получателям. SHA-256 защищает от
повреждений, но не подтверждает личность автора: подписи отсутствуют.
Удаление человека из текущего дерева не удаляет его из прошлых снимков.
Не отправляйте историю, если в ней остались данные, которыми не хотите
делиться.

**Фотографии и медиа пока не входят в .ftree.** Для полноценного
резервного копирования документов используйте прежний ZIP-бэкап.
Новый формат не заменяет резервные копии.

Конфликт выявляется на уровне GEDCOM-записи целиком, а не отдельных
полей. Две правки имени и даты одного человека также вызывают конфликт.
При одновременном создании разных людей с одним GEDCOM ID возникает
конфликт; автоматической переиндексации в первой версии нет.
Выбирая одну версию, пользователь может отклонить другую запись.

Нельзя автоматически объединить два совершенно независимых дерева без
общей истории (разные UUID). Для этого нужен отдельный инструмент
сопоставления одинаковых персон.

Отсутствуют: шифрование, вложения, криптографические подписи участников,
откат через UI к старой версии, визуальные различия отдельных полей,
сетевой обмен и автоматическое устранение коллизий ID. Это план следующих
этапов, не функции версии 0.2.3.

## Тестирование

VersionedTreeArchiveTest проверяет импорт/экспорт, разделение ветвей,
поиск общего предка, запись merge-коммита, обязательное разрешение
конфликтов, защиту от подмены SHA-256 и ZIP path traversal.
FileTreeRepositoryTest проверяет накопление истории при обычном сохранении.
Android UI-тест проверяет доступность новых команд меню.

Нужна отдельная ручная проверка системного файлового диалога на телефоне.
